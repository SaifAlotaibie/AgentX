# نظام وكيل قوى الذكي - Complete System

## 🎉 اكتمل النظام بالكامل!

تم بناء نظام متكامل للذكاء الاصطناعي لخدمة العملاء في منصة قوى، مع دعم **اللغة العربية فقط** وتكامل كامل بين الواجهة الأمامية والخلفية.

---

## 🚀 الميزات المنفذة

### Backend (الخلفية)
✅ **وكيل ذكي بالكامل** مع LangChain + LangGraph  
✅ **استجابات عربية فقط** - كل الرسائل بالعربية  
✅ **نظام تخزين السير الذاتية** (JSON-based DB)  
✅ **نظام تخزين التذاكر** (JSON-based DB)  
✅ **WebSocket للتواصل الفوري**  
✅ **API endpoints** لجلب السير الذاتية والتذاكر  
✅ **معالجة النوايا** (إضافة/تعديل/حذف السيرة الذاتية + الأسئلة)  
✅ **تتبع العمليات** مع تحديثات فورية  

### Frontend (الواجهة)
✅ **React + Vite + TailwindCSS**  
✅ **React Router** - صفحات منفصلة  
✅ **3 صفحات رئيسية**: المحادثة، لوحة التحكم، التذاكر  
✅ **واجهة عربية بالكامل** - كل النصوص بالعربية  
✅ **اتصال حقيقي بالخلفية** - لا محاكاة  
✅ **عرض السير الذاتية المحفوظة**  
✅ **عرض التذاكر المفتوحة والمغلقة**  
✅ **Framer Motion** للحركات السلسة  
✅ **إدخال صوتي** مع Web Speech API

## 🎯 كيفية الاستخدام

### 1. تشغيل الخلفية (Backend)

```bash
cd backend/Agents
python -m uvicorn app:app --reload --port 8000
```

**الخادم يعمل على:** `http://localhost:8000`  
**WebSocket:** `ws://localhost:8000/ws/{sessionId}/{userId}/{userRole}`

### 2. تشغيل الواجهة (Frontend)

```bash
cd front-end
npm run dev
```

**الواجهة تعمل على:** `http://localhost:5173`

## 💬 سيناريو الاستخدام الكامل

### الخطوة 1: إنشاء سيرة ذاتية جديدة

1. افتح المتصفح على `http://localhost:5173`
2. في صفحة المحادثة، اكتب: **"أريد إضافة سيرتي الذاتية"**
3. الوكيل سيفتح تذكرة ويسألك عن:
   - الاسم الكامل
   - المسمى الوظيفي
   - البريد الإلكتروني
   - رقم الهاتف
4. أجب على كل سؤال
5. سيتم حفظ السيرة تلقائياً
6. الوكيل سيسألك: "هل أنت راضٍ؟ هل تريد إغلاق التذكرة؟"
7. اكتب: **"نعم"** لإغلاق التذكرة

### الخطوة 2: عرض السيرة الذاتية في لوحة التحكم

1. انقر على **"لوحة التحكم"** في القائمة العلوية
2. سترى جميع السير الذاتية المحفوظة
3. كل سيرة تعرض:
   - الاسم
   - المسمى الوظيفي
   - معلومات الاتصال
   - تاريخ الإنشاء والتحديث
   - رقم السيرة (ID)

### الخطوة 3: عرض التذاكر

1. انقر على **"التذاكر"** في القائمة العلوية
2. سترى جميع التذاكر (المفتوحة والمغلقة)
3. إحصائيات التذاكر في الأعلى
4. لكل تذكرة:
   - النوع (إضافة/تعديل/حذف)
   - الحالة (مفتوحة/مغلقة)
   - الوصف
   - التاريخ

### الخطوة 4: تعديل السيرة الذاتية

1. ارجع لصفحة المحادثة
2. اكتب: **"أريد تعديل سيرتي الذاتية"**
3. اختر القسم المراد تعديله
4. أدخل القيمة الجديدة
5. أكد الإغلاق عند الانتهاء

### الخطوة 5: طرح سؤال

1. في صفحة المحادثة، اكتب أي سؤال عن خدمات قوى
2. مثال: **"ما هي شروط التوظيف؟"**
3. الوكيل سيجيب مباشرة من قاعدة المعرفة

## 🔍 الميزات التقنية

### Backend APIs

| Endpoint | Method | الوصف |
|----------|--------|-------|
| `/` | GET | معلومات API |
| `/ws/{sessionId}/{userId}/{userRole}` | WebSocket | اتصال فوري |
| `/agent/message` | POST | إرسال رسالة (HTTP) |
| `/resumes/{userId}` | GET | جلب جميع السير الذاتية |
| `/resume/{userId}/{resumeId}` | GET | جلب سيرة ذاتية محددة |
| `/tickets/{userId}` | GET | جلب جميع التذاكر |

### WebSocket Events

**من العميل للخادم:**
```json
{
  "type": "user_message",
  "sessionId": "S123",
  "userId": "U123",
  "userRole": "employee",
  "message": "أريد إضافة سيرتي الذاتية"
}
```

**من الخادم للعميل:**
```json
{
  "type": "chat_message",
  "role": "assistant",
  "message": "ما هو اسمك الكامل؟",
  "timestamp": "2025-11-11T17:32:00Z"
}
```

```json
{
  "type": "process_update",
  "steps": [
    {"id": "open_ticket", "title": "فتح تذكرة", "status": "done"},
    {"id": "gather_info", "title": "جمع المعلومات", "status": "in_progress"}
  ]
}
```

```json
{
  "type": "ticket_update",
  "ticket": {
    "ticketId": "T123",
    "status": "open",
    "type": "resume_add"
  }
}
```

## 🎨 الواجهة الأمامية

### الصفحات

1. **صفحة المحادثة** (`/`)
   - محادثة فورية مع الوكيل
   - إدخال نصي وصوتي
   - عرض قائمة الخطوات
   - رسائل ذكية متحركة

2. **لوحة التحكم** (`/dashboard`)
   - عرض جميع السير الذاتية
   - إحصائيات
   - بطاقات تفاعلية لكل سيرة
   - أزرار العرض والتحميل

3. **صفحة التذاكر** (`/tickets`)
   - قائمة جميع التذاكر
   - تصنيف حسب الحالة
   - إحصائيات التذاكر
   - ألوان مميزة لكل حالة

### التنقل

شريط علوي ثابت يحتوي على:
- شعار قوى
- أزرار التنقل (المحادثة، لوحة التحكم، التذاكر)
- مؤشر الصفحة النشطة

## 🐛 استكشاف الأخطاء

### إذا لم يتصل WebSocket:
1. تأكد من تشغيل الخلفية على المنفذ 8000
2. افحص console المتصفح للأخطاء
3. تأكد من عدم وجود جدار ناري يحجب الاتصال

### إذا لم تظهر السير الذاتية:
1. تأكد من إنشاء سيرة ذاتية أولاً
2. افحص `backend/Agents/logs/resumes/`
3. تأكد من استخدام نفس `userId`

### إذا لم يعمل الإدخال الصوتي:
1. امنح المتصفح الإذن للميكروفون
2. استخدم HTTPS في الإنتاج
3. تأكد من دعم المتصفح للـ Web Speech API
